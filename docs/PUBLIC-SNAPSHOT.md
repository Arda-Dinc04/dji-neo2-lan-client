# Public source snapshot

Prepared 2026-11-04 from development source `neo2-control` at `559d9883d90bea26877a04c660f79e6d8bcfa3d2`.

This repository starts a new public history. It contains tracked source files,
tests and build tools, with example device addresses and deployment endpoints
anonymized. Device captures, photographs, maps, model weights, vendor binaries,
credentials, local identities and development Git history are not included.
Historical source hashes are provenance references, not public replay evidence.

The private binary-analysis toolkit and its tests are omitted: they include
proprietary instruction excerpts or SDK-log decryption parameters. Retained
JSON fixtures contain protocol results, synthetic inputs and provenance hashes;
they are offline comparison data, not a redistributable vendor executable.
